# VimiOTP

一个极简风格的 Chrome OTP 验证码管理扩展。

## 功能

- **手动添加** — 输入服务商、账户名和 Base32 密钥
- **扫描二维码** — 自动识别当前网页上的 OTP 二维码
- **实时显示** — 圆环 + 进度条双倒计时，自动刷新验证码
- **一键复制** — 点击验证码即可复制到剪贴板
- **搜索筛选** — 账户超过 3 个时自动显示搜索栏
- **编辑账户** — 修改服务商和账户名称
- **导出备份** — 导出所有密钥为 JSON 文件
- **导入恢复** — 从备份文件导入，自动跳过重复项
- **防重复** — 添加时自动检测密钥是否已存在
- **本地存储** — 数据保存在浏览器本地，安全私密

## 安装

1. 下载或克隆本项目
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目目录

## 使用

1. 点击浏览器工具栏中的 VimiOTP 图标
2. 点击右上角 **+** 按钮添加新的 OTP
3. 选择「手动输入」或「扫描二维码」方式添加
4. 点击验证码即可复制

## 技术栈

- Chrome Manifest V3
- jsSHA (TOTP 生成)
- jsQR (二维码识别)

## 构建

```bash
make build    # 打包为 zip
make clean    # 清理构建产物
```
